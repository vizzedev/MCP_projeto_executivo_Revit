# Perfil do escritório

Arquivo: `config/escritorio.json`. Preenchido uma vez por escritório (pelo instalador ou na primeira conversa).
Valores com `<<…>>` são marcadores ainda não preenchidos.

| Campo | Uso |
|---|---|
| `nome` | Nome da organização (carimbo ARQ) |
| `endereco_contato` | Descrição da organização (carimbo ARQ): endereço, telefone, rede social em uma linha |
| `prefixo` | Prefixo de nomenclatura (ex.: "VZ-") — usado ao criar tipos, vistas e famílias |
| `responsavel_padrao.autor`, `.cau` | Autor do projeto / Numero CAU |
| `executor_padrao.nome`, `.crea` | Executor da obra / Numero CREA |
| `observacoes_gerais` | OBSERVAÇÕES GERAIS (carimbo DET) |
| `caminhos.pasta_base` | Pasta-base no servidor |
| `caminhos.template_master` | Template master (.rte) no servidor |
| `caminhos.pasta_projetos` | Pasta padrão para salvar projetos novos |
| `carimbos.proposta` / `.arq` / `.det` | Família de carimbo de cada caderno |
| `numeracao.arq` / `.det` | Formato do número da folha: "n/N" ou "0n/0N" |
| `vista_implantacao` | Vista com as regiões de área (padrão "IMPLANTAÇÃO") |
| `revit_versao` | Versão do Revit do template |
